ASL mode self-test

Runs the ASL model on made-up landmark sequences (no camera) in this browser, and on the SignBridge server if it is running, then compares the two. It checks that the model loads, how long one sign takes, and that both runtimes give the same answer for the same input. It says nothing about accuracy on real signing: that is measured by notebooks/asl_mode_eval.ipynb.
